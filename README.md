🍽️ API Restaurant

API desenvolvida durante o curso da Rocketseat, com foco em construção de aplicações back-end utilizando Node.js, Express, TypeScript, Knex e SQLite3.

🚀 Tecnologias
Node.js

Express

TypeScript

Knex.js

SQLite3

📌 Funcionalidades
Cadastro de restaurantes

Listagem de restaurantes

Atualização de informações

Exclusão de registros

Endpoints RESTful bem estruturados

🛠️ Como executar
bash
# Clone o repositório
git clone https://github.com/soarezzgzs/api-restaurant

# Instale as dependências
npm install

# Execute as migrations
npm run knex:migrate

# Inicie o servidor
npm run dev
🔍 Testes com Insomnia
O repositório já contém a collection do Insomnia para facilitar os testes.
Basta importar o arquivo .yaml no Insomnia e executar as requisições.
